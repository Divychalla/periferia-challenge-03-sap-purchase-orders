# Periferia Challenge 03 — SAP Purchase Orders

This public repository contains the Challenge 3 solution. The full source tree and fixtures are packaged in [`challenge-03-source.zip`](challenge-03-source.zip); the archive preserves the original directory structure. The design and implementation notes are available in [`SOLUTION.md`](SOLUTION.md), and the requirements are summarized in [`PRD.md`](PRD.md).

## Run locally

1. Download and extract `challenge-03-source.zip` into a new directory.
2. From that directory, run:

   ```bash
   pnpm install
   pnpm run build
   pnpm demo
   ```

The demo runs without an API key. Fixture data is fictional, and the SAP adapter is simulated.
